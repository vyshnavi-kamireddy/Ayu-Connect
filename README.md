# 🌿 AyuConnect

**Rooted in Nature. Powered by Tradition.**

## 📌 Overview

**AyuConnect** is a website that helps users **find natural remedies for common symptoms**. It provides **easy-to-follow instructions, recommended dosages, and safety tips** for each remedy. Built using **React, HTML, CSS, and JavaScript**, it offers a clean, interactive, and user-friendly experience.

## 🎯 Features

✅ **Search Symptoms**  
- Enter symptoms like cold, headache, cough, or eye pain to find remedies.

✅ **Personalized Remedies**  
- Get natural remedies suggested based on the symptoms you enter.

✅ **Step-by-Step Instructions**  
- Each remedy comes with clear preparation and usage guidance.

✅ **User Reviews**  
- Read experiences and feedback from other users about the remedies.

✅ **Safety Tips**  
- Provides guidance to use remedies safely, including allergies and dosage precautions.

---

## 🔧 Technologies Used

- **Frontend:** React, HTML, CSS, JavaScript  
- **Logic:** Hugging Face API for AI-based remedy suggestions, dynamic state updates  
- **Interactivity:** Search functionality, clickable remedy cards
